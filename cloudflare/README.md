# مسار الاتصال البديل لمنصة أَثَر

هذا المسار مضاف في مستودع التطوير فقط. لا يغيّر نشر GitHub Pages الحالي ولا يحذف أو ينقل أي بيانات من Google Sheets.

## لماذا هذا المسار؟
- المتصفح يتصل بعنوان من نفس نطاق المنصة: `/api/athar`.
- Cloudflare Pages Function تتصل بخادم Apps Script من جهة الخادم.
- لا يعتمد هذا المسار على iframe أو postMessage أو قراءة استجابة Google من المتصفح.
- Apps Script يعيد JSON عند وجود `transport=json`، مع الإبقاء على استجابة HTML القديمة للتوافق.

## إعداد Cloudflare Pages
أنشئ مشروع Pages مرتبطًا بالمستودع `aboasmaa2273-code/ather-development` فقط:
- Production branch: `main`
- Build command: `npm run build`
- Build output directory: `dist`
- Root directory: اتركه فارغًا (جذر المستودع).

أضف متغير البناء التالي:
- `VITE_ATHAR_API_TRANSPORT` = `proxy`

وأضف متغير البيئة الخاص بالـ Function:
- `ATHAR_GAS_ENDPOINT` = رابط نشر Apps Script الحالي المنتهي بـ `/exec`.

الملف `public/_routes.json` يحدد تشغيل Functions على مسارات `/api/*) فقط؛ حتى لا تُستهلك حصة Functions عند تحميل ملفات الواجهة الثابتة.

## خطوة Apps Script المطلوبة قبل التفعيل
يجب نقل النسخة المحدّثة من `gas/SharedDatabase.gs` إلى مشروع Apps Script الحي ونشر إصدار جديد. هذا التعديل يضيف استجابة JSON لطلبات الوسيط فقط، ويحافظ على المسار القديم. لا تنفذ ذلك قبل مراجعة النسخة الحالية ومطابقة الملف، ولا تشغّل دالة إعداد قاعدة البيانات.

## التحقق قبل اعتماد النسخة
1. تأكد من أن Cloudflare نشر المشروع وظهرت صفحة أَثَر.
2. اختبر `POST /api/athar` بطلب ping؛ يجب أن يعيد JSON فيه `success: true`.
3. اختبر تسجيل الدخول بحساب مخوّل.
4. اختبر القراءة ثم حفظ سجل تجريبي غير حساس ثم التحقق من ظهوره في Google Sheets.
5. اختبر الصلاحيات بحساب معلم وحساب إداري قبل اعتماد رابط النسخة الجديدة.

## الحماية والتوافق
- لا يضع المشروع كلمات مرور أو مفاتيح API في ملفات الواجهة.
- يبقى التحقق من الجلسات والصلاحيات في Apps Script.
- لا يعيد الوسيط إرسال الطلب عند فقد الاستجابة؛ لتجنب تكرار عمليات الحفظ.
- لا تفعّل `VITE_ATHAR_API_TRANSPORT=proxy` على نسخة GitHub Pages؛ هذا المتغير مخصص لبناء Cloudflare.
- لا تُحذف أو تُعدّل بيانات Google Sheets بواسطة هذه الإضافات.

## حدود الخطة المجانية
وفق وثائق Cloudflare الحالية، حد Workers Free هو 100,000 طلب يوميًا، وPages Functions تُحاسب ضمن Workers. ويُستثنى مسار الواجهة الثابتة من تشغيل Function بفضل `_routes.json`. إذا تجاوزت طلبات API اليومية الحد المجاني، قد تتوقف Function عن معالجة الطلبات إلى أن تتجدد الحصة أو تُغيّر الخطة.

## إعادة النشر بعد تعديل متغيرات البيئة
عند إضافة أو تعديل متغيرات Pages أو Functions من لوحة Cloudflare، يجب إنشاء نشر جديد حتى تُحقن القيم في نسخة الإنتاج. يكفي إجراء تحديث توثيقي آمن على هذا الملف في فرع main لتشغيل النشر التلقائي؛ لا يتطلب ذلك تعديل بيانات Google Sheets أو تغيير رابط Apps Script.
